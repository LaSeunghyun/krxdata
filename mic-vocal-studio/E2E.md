# MIC VOCAL — E2E 테스트 워크플로우

브라우저(Playwright, 모바일 뷰포트 400×880)로 실제 클릭/입력하며 검증.

| # | 시나리오 | 단계 | 기대 결과 |
|---|---|---|---|
| W1 | 권한 가드 | 비로그인 상태로 `booking.html` 접근 | `login.html`로 리다이렉트 |
| W2 | 방문자 네비 | 비로그인 홈 | 하단탭 = 홈·커뮤니티 2개, 우상단 "로그인" |
| W3 | 학생 로그인 | login → student 계정 → 예약 | booking 접근됨, 하단탭 4개(홈·클래스·커뮤니티·마이) |
| W4 | 원장 로그인 | login → director | 하단탭에 "원장" 노출, admin 접근 |
| W5 | 콘텐츠 추가 | admin→콘텐츠→URL 입력→추가 | 영상 목록+1, 홈 피드에 반영 |
| W6 | 콘텐츠 삭제 | admin→콘텐츠→삭제 | 영상 목록−1, 홈 반영 |
| W7 | 권한 변경 | admin→회원·권한→역할 변경 | users 역할 갱신 |
| W8 | 강사 휴강 | coach 로그인→내 예약→휴강 | booking.offday=true, 학생 mypage "휴강" |
| W9 | 강사 휴가 | coach→휴가 신청 | leaves 추가, 예약 차단 |
| W10 | 반응형 | 360/768/1280 폭 | 레이아웃 깨짐 없음 |
